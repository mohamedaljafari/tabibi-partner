# حزمة طبيبي البصرية

هذه الحزمة مبنية على دليل الهوية المرفق، مع اعتماد الأخضر الزيتي والبيج والذهبي، والرمز الهلالي مع المنزل وغصن الزيتون كرمز رئيسي.

## طريقة الاستخدام

استخدم `tabibi_ad_01_home_care_hero.png` أو `tabibi_ad_04_team_banner.png` لإعلان التعاقد أو الانضمام إلى الفريق، ثم أضف المسمى الوظيفي ووسيلة التواصل في المساحة البيجية الفارغة. استخدم `tabibi_ad_02_care_visit.png` للخدمات المنزلية، و`tabibi_ad_03_app_device.png` لإعلانات التطبيق أو المواعيد.

قبل النشر، استبدل الحقول بين الأقواس في ملف القوالب، وراجع الهاتف والرابط والمدينة واسم الوظيفة. لا تضع النص فوق الوجوه أو اليدين، ولا تستخدم الرموز الثانوية الثلاثة معًا في منشور واحد.
